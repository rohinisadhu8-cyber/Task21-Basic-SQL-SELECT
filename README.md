Task 21: Basic SQL SELECT

Project Overview

This project is part of the Data Analytics track at Veda Technology. It focuses on practising basic SQL queries using PostgreSQL to retrieve, filter, and sort employee data.

Objective

To understand SQL fundamentals and practise the "SELECT", "WHERE", and "ORDER BY" clauses.

Tools Used

- PostgreSQL
- OneCompiler Online SQL Editor

Dataset

A sample employee dataset containing:

- Employee ID
- Employee Name
- Department
- Salary

SQL Concepts Practised

1. "SELECT" – Retrieve all records from a table.
2. Select specific columns.
3. "WHERE" – Filter records by department.
4. Filter employees by salary.
5. "ORDER BY ASC" – Sort salaries in ascending order.
6. "ORDER BY DESC" – Sort salaries in descending order.
7. Filter employees by department.
8. Filter employees based on salary conditions.
9. Combine "WHERE" and "ORDER BY".
10. "BETWEEN" – Filter salaries within a specified range.

Project Outcome

- Practised 10 SQL queries.
- Learned how to retrieve, filter, and sort employee data.
- Improved understanding of basic SQL operations.

How to Run

1. Open a PostgreSQL online SQL editor.
2. Copy the SQL code from "Task21_Basic_SQL_SELECT.sql".
3. Paste it into the editor.
4. Click Run to execute the queries.
5. Review the query results.

Conclusion

This project helped me build a foundation in SQL and understand how databases can be queried using PostgreSQL.
